# Matching and proposal flow

1. Normalize titles, skills, descriptions, rates, and client metadata.
2. Extract required experience and explicit application rules.
3. Compare opportunity phrases with structured profile skills and supporting evidence.
4. Select the strongest eligible profile above a configurable score.
5. Generate a proposal using the opportunity, profile evidence, and detected rules.
6. Validate required prefixes, profile identity, length, and prohibited patterns.
7. Write the result to a human review surface and record processing state.

AI output remains subject to human review before any external submission.
