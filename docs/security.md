# Security and compliance

- `.env`, service-account JSON, database credentials, webhook URLs, browser state, logs, and profile sheets are excluded.
- The public repository does not contain executable scraping or anti-bot interaction code.
- Proposal drafts remain private until reviewed by a person.
- Public documentation avoids personal team profiles and customer opportunity content.
- Credentials found in the working folder should be rotated before continued operation.
- Automation must respect platform terms, authorization boundaries, and applicable data-handling requirements.
